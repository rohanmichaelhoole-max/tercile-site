Privacy Policy

Last updated: 9 November 2026

Tercile ("the app") provides attribute-level merchandising analytics for Shopify stores. This policy explains what data the app accesses, what it stores, and how it is handled. The app is operated by Formateca (contact: hello@tercile.app).

What we access

  • Product data — titles, descriptions, tags, metafields, variants, images, status. Used to generate attribute tags (e.g. colour, fabric, fit).
  • Order data — line items, quantities, prices, discounts, refunds, and order dates. Used to compute revenue and demand metrics per attribute.

What we do not store

We do not store customer personal information. No names, email addresses, shipping or billing addresses, phone numbers, or payment details are persisted by the app. Order records are stored only as line items, quantities, amounts, and dates.

AI processing

Product page text (and, where enabled, product images) is sent to Anthropic's Claude API to generate attribute tags and analytical summaries. Only product information is sent — never customer data. Anthropic does not train models on this API data.

Storage and security

Data is stored in a managed PostgreSQL database hosted on Railway. Access is restricted to the app's own services. Data is transmitted over TLS.

Data retention and deletion

  • Uninstalling the app stops all data collection immediately.
  • We honour Shopify's GDPR webhooks: shop/redact deletes all stored data for a shop after uninstall; customers/redact and customers/data_request are acknowledged — as we store no customer personal data, there is nothing to return or redact.
  • You may request earlier deletion at any time via hello@tercile.app.

Cookies

The app runs embedded in the Shopify admin and uses only the session tokens Shopify provides for authentication. This marketing site sets no cookies and runs no trackers.

Changes

We will update this page when the policy changes and note the date above.
